How it works

Frequently Asked Questions

What is a masked Aadhaar and why use it?

A masked Aadhaar hides the first 8 digits of your 12-digit Aadhaar number while leaving only the last 4 digits visible. UIDAI recommends sharing masked copies for routine verification (hotels, SIM cards, rentals) so your full ID number cannot be misused.

Why add a purpose watermark to ID copies?

Writing who the copy is for and the exact date across the document prevents a leaked or intercepted copy from being reused to open fraudulent accounts, take loans, or register SIM cards elsewhere.

Is anything uploaded to a server?

No. DocStamp is a single static HTML file with zero backend, zero analytics, and zero external requests. All rendering, masking, and re-encoding happen strictly inside your browser's HTML5 Canvas.

Which image formats are supported?

You can import JPG, PNG, and WebP images via drag-and-drop, file picker, or clipboard paste. Exports are freshly re-encoded as clean JPG or PNG files without any embedded EXIF/GPS tags.

Is DocStamp free and open source?

Yes, DocStamp is 100% free with no watermarks of its own, no sign-ups, and full source code available on GitHub for anyone to inspect, audit, or self-host.
